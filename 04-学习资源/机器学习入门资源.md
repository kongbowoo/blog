# 机器学习入门资源

> 概述：机器学习入门阶段收集的学习资料，以经典实战型教材为主，配套源码便于动手练习。

## 电子书：Machine Learning in Action

- 书名：*Machine Learning in Action*（Peter Harrington 著）
- 特点：以 Python 从零实现分类、聚类、回归等经典算法，侧重工程实践，适合入门。

## 学习路线建议

1. 环境准备：Python 2.7/3.x + NumPy + Matplotlib。
2. 按章节顺序实现 kNN、决策树、朴素贝叶斯、Logistic 回归、SVM 等分类算法。
3. 进阶阅读：配合李航《统计学习方法》或周志华《机器学习》（西瓜书）理解算法推导。
